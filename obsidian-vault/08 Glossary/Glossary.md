# Glossary

## Canonical

Approved implementation authority.

## Candidate

Proposed by Archetype, but not approved.

## Clarification Package

The only valid package for weak context.

## Context Matrix

Artifact that classifies required decisions, evidence levels, blockers, readiness tier, and next question.

## Gate Report

Artifact-backed readiness report.

## Weak Context

Context where the next artifact would depend on unapproved invention.
