# ADR-0002 One Question Clarification

## Decision

Archetype asks one clarification question at a time.

## Reason

Bulk questions feel like a form and produce worse UX. One high-impact question lets the context matrix update after each answer.

## Consequence

Clarification artifacts need a question queue and a single `next_question`.
