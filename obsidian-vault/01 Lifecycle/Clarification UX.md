# Clarification UX

Clarification happens one question at a time.

## Algorithm

1. Read idea, imported files, screenshots, and repo context.
2. Build [[Context Matrix]].
3. Mark decisions as confirmed, candidate, missing, conflicted, or blocked.
4. Select highest-impact missing or conflicted blocker.
5. Ask exactly one question.
6. Update context matrix after answer.
7. Repeat until next lifecycle gate is safe.
8. Present assumptions and candidates for approval.
9. Generate canonical contract only after approval.

## First Question For Vague Dashboard Prompt

```txt
Who is the primary user of this marketing admin dashboard?
```
