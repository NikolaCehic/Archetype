# No Canonical Contract From Inference

Inference can suggest. It cannot decide.

## Bad

```txt
marketing dashboard -> campaigns, billing, settings become accepted routes
```

## Good

```txt
marketing dashboard -> campaigns, billing, settings become candidate routes
```

The user or imported context must approve candidates before canonicalization.
