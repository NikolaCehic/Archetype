# No Implementation Before Approval

Implementation begins only after user approval of the contract or assumptions.

## Required

- Approval artifact.
- Canonical spec.
- Test-first contract.
- Initial red evidence.

## Forbidden Before Approval

- Frontend implementation instructions.
- Target frontend write plan.
- Agent handoff claiming implementation readiness.
