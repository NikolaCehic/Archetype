# Canonical Package

A canonical package exists only after approval.

## Required Before Creation

- Context sufficient.
- Assumptions approved.
- Specialist blockers resolved or converted into user questions.
- Approval artifact exists.

## May Contain

- `spec/archetype-spec.json`
- `frontend-agent-contract/implementation-rules.json`
- `test-first/test-first-contract.json`
- Verification contracts.
