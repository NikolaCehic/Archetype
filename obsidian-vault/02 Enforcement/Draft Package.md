# Draft Package

A draft package can contain candidate product architecture, but cannot instruct implementation.

## Allowed

- Candidate product model.
- Candidate routes.
- Candidate screens.
- Candidate design system.
- Candidate contracts.
- Assumption ledger.

## Forbidden

- Canonical spec.
- Test-first implementation obligations.
- Frontend implementation instructions.
