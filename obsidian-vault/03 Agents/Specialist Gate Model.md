# Specialist Gate Model

Specialist agents review lifecycle artifacts before they become canonical.

## Rule

Creator and approver must be different roles.

## Review Artifacts

- Product architect review.
- Experience architect review.
- Frontend architect review.
- Design system review.
- Frontend practice review.
- TypeScript strictness review.
- Accessibility review.
- Pixel review.
- Specialist summary.
